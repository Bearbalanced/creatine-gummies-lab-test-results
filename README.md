## What this is

Creatine degrades in heat, moisture and acid, so the creatine content of a gummy can differ from its label. This dataset records independent finished-product measurements of creatine monohydrate in creatine gummies, one row per production lot, with the lab report number for each row.

Version 1 contains four lots of Bear Balanced Creatine Gummies tested by Eurofins Food Integrity & Innovation in August 2026. It is published by the manufacturer. The original lab reports are included so every number can be checked. The contract manufacturer's name and address are redacted in the PDFs; nothing else is altered.

## Method

Finished gummies from each production lot were submitted to Eurofins (ISO 17025). Creatine monohydrate was quantified by UPLC and reported per 3-gummy serving.
